# PC-PersonalControl

Управление поддерживаемыми вентиляторами и питанием Windows, просмотр датчиков, а также управление компьютером через Telegram.

## Структура

- [`desktop/`](desktop/README.md) — локальная версия приложения с собственным Telegram-ботом.
- [`cloud/client/`](cloud/client/README.md) — версия Windows-клиента с облачным агентом.
- [`cloud/server/`](cloud/server/README.md) — API, Telegram-бот, сайт/Mini App и инструменты выпуска подписанных обновлений.

Облачная версия требует самостоятельно развернуть сервер и настроить бота, HTTPS-домен и ключ подписи. Локальная версия работает отдельно и не требует облачного сервера. Существующие каталоги `%LOCALAPPDATA%\FanPilot` и служебные идентификаторы сохранены ради совместимости пользовательских настроек.

Исходники сборок и сайта находятся в соответствующих каталогах; отдельный репозиторий сайта, если используется, обновляется независимо.
