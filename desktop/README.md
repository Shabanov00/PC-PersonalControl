# PC-PersonalControl

PC-PersonalControl объединяет доступное через Windows управление вентиляторами, показ температур, профили электропитания и отправку Wake-on-LAN пакетов в одном окне.

## Запуск

Запустите `PC-PersonalControl.exe`. При первом запуске Windows запросит подтверждение администратора: контроллерам датчиков и вентиляторов нужны повышенные права. EXE содержит приложение и DLL; он извлекает проверенные компоненты в `%LOCALAPPDATA%\FanPilot\Runtime`. Каталог `%LOCALAPPDATA%\FanPilot` сохранён для совместимости с прежними версиями: там находятся настройки и зашифрованная DPAPI-конфигурация бота. Устанавливать драйверы и прошивки не нужно.

Исходную PowerShell-версию можно запустить через `Start-PC-PersonalControl.cmd`. Для повторной сборки EXE запустите `Build-PC-PersonalControl.ps1` из 64-разрядной Windows PowerShell; сборка проверяет SHA-256 включаемых DLL.

## Обновления

В разделе **«Питание и пробуждение»** нажмите **«Проверить обновления»**. PC-PersonalControl проверяет публичные GitHub Releases репозитория `Shabanov00/fanpilot-web`; если версия новее установленной, кнопка откроет страницу релиза. Скачайте `PC-PersonalControl-project.zip` (в старых релизах — `FanPilot-project.zip`), закройте программу, распакуйте архив в новую папку и запустите новый `PC-PersonalControl.exe`. Обновление не устанавливается автоматически и не запускает загруженные файлы.

Чтобы выпустить обновление, увеличьте `$script:PCPersonalControlVersion` в `PC-PersonalControl.ps1` (формат `1.1.1`), выполните `Build-PC-PersonalControl.ps1`, создайте ZIP проекта и опубликуйте GitHub Release с тегом вида `v1.1.1`. Приложите архив с точным именем `PC-PersonalControl-project.zip`. Не включайте в репозиторий или архив пользовательскую конфигурацию `%LOCALAPPDATA%\FanPilot\telegram.json`; токены не должны попадать в релизы.

## Охлаждение

- **Тихо** — спокойная кривая, минимум 30%.
- **Игры** — более быстрая реакция на температуру.
- **Максимальный обдув** — 100% на доступных программных каналах.
- **Авто BIOS** — возвращает канал встроенному контроллеру.
- **Своя кривая** — точки температуры/скорости и выбор температурного датчика для каждого канала.

Приложение показывает только каналы, которые оборудование предоставляет для программного управления. На проверенном ПК обнаружены 2 температурных датчика и одна группа **видеокарты NVIDIA**, объединяющая 2 синхронных вентилятора. Вентилятор процессора и вентиляторы корпуса показаны отдельно; плата не предоставила для них программные каналы, поэтому ими продолжает управлять BIOS. Приложение не может обойти это ограничение через драйвер или прошивку. Кривые повышают скорость при высокой температуре; при потере датчика приложение пытается вернуть BIOS-контроль. Одновременно может работать только один экземпляр. При нормальном закрытии все каналы возвращаются в аппаратный автоматический режим.

Если процесс приложения пришлось принудительно завершить, выполните `PC-PersonalControl.exe -RestoreDefaults`; для закрытия зависшего экземпляра перед восстановлением используйте `PC-PersonalControl.exe -RestoreDefaults -CloseProcessId <PID>`.

## Питание и температура

На вкладке **«Питание и пробуждение»** можно выбрать доступный план Windows и задать максимальное состояние CPU при питании от сети (50–100%). Низкое ограничение может уменьшить нагрев ценой производительности.

Windows не предоставляет универсальной безопасной настройки целевой температуры CPU или GPU. PC-PersonalControl показывает доступные показания датчиков и регулирует поддерживаемые вентиляторы; защитные температурные пределы остаются у BIOS и драйвера видеокарты. Приложение не меняет предел мощности или напряжение GPU/CPU.

## Wake-on-LAN

Введите MAC-адрес сетевого адаптера другого компьютера и нажмите **«Отправить пакет пробуждения»**. Приложение должно работать на включённом компьютере-отправителе. Целевой компьютер должен поддерживать Wake-on-LAN, а его сетевой адаптер, BIOS и сетевое подключение — быть настроены для пробуждения. Пакет отправляется только в локальную сеть. Чтобы разбудить этот компьютер телефоном, пакет должен отправить роутер или другое постоянно включённое устройство; TP-Link RE220 не перепрошивается и сам по себе не обеспечивает удалённое пробуждение через интернет. Для безопасного удалённого доступа используйте VPN к домашней сети, если маршрутизатор поддерживает эту функцию.

## Telegram

На вкладке **«Питание и пробуждение»** можно подключить бота для просмотра статуса, Wake-on-LAN, сна, блокировки, немедленного выключения/перезагрузки и таймера выключения. Клавиатура Telegram содержит также управление громкостью: изменение на 2%, mute и установка собственного значения от 0 до 100%. Это не удалённый рабочий стол: бот принимает только фиксированные действия, а не произвольные команды или shell-команды.

Бот ежедневно в 00:00 по местному времени удаляет из личного чата отслеживаемые сообщения владельца и бота, накопленные после включения этой функции. Список ID хранится локально в `%LOCALAPPDATA%\FanPilot\telegram-chat-cleanup.json`, чтобы переживать перезапуск. Telegram Bot API не позволяет боту очистить всю историю и не разрешает удалять сообщения старше 48 часов; более ранние и неотслеживаемые сообщения останутся. Журналы приложения и бота при этом не очищаются.

**Сначала отзовите любой токен, который был опубликован в переписке, через BotFather. Создайте новый токен и вводите только его в PC-PersonalControl.** Приложение хранит токен с помощью Windows DPAPI, привязанной к текущей учётной записи Windows; токен не помещается в EXE и не записывается в журнал. После сохранения токена запустите бота и отправьте ему показанную PC-PersonalControl команду `/pair КОД` в личном чате в течение 10 минут. Управлять сможет только привязанный Telegram-аккаунт; для смены владельца удалите `%LOCALAPPDATA%\FanPilot\telegram.json` при остановленном боте и выполните сопряжение заново.

Не отправляйте боту пароли и не используйте его для автоматического ввода паролей. MAC-адрес Wake-on-LAN сохраняется отдельно от токена, но перед его изменением остановите бота. Выключение и перезагрузка выполняются сразу, без дополнительного подтверждения; приложения не закрываются принудительно, но могут потерять несохранённые данные.

Нажмите **«Запустить + автозапуск»**, чтобы создать задачу Windows и запустить бота. Задача работает независимо от окна PC-PersonalControl и стартует при входе в Windows под той же учётной записью, которой зашифрован токен. Она перезапускает бота при ошибочном завершении. Бот доступен, пока ПК включён и пользователь вошёл в Windows; блокировка экрана не останавливает его. Если ПК спит, выключен или пользователь вышел из системы, бот не может отвечать. **«Остановить сейчас»** останавливает только текущий процесс; **«Отключить автозапуск»** удаляет задачу Windows. Закрытие PC-PersonalControl не останавливает бота.

Кнопка **«Таймер выключения»** попросит длительность: например `30 секунд`, `15 мин`, `2 часа`, `1 день` или `1ч 30м`. Допустимый диапазон — от 1 секунды до 10 лет (лимит Windows). **«Отменить таймер»** отменяет назначенное выключение, в том числе если бот перезапускался.

### Веб-панель Telegram

Исходники адаптивной панели находятся в `web/index.html`. Для работы в Telegram страницу нужно разместить на публичном HTTPS-хостинге. Затем в PC-PersonalControl укажите полный URL в разделе **«Веб-панель / Telegram Mini App»**, перезапустите бота и отправьте `/start`. Бот покажет кнопку открытия приложения под строкой ввода. Для ссылки формата `https://t.me/<bot_username>/<appname>` владелец должен создать Mini App в BotFather, задать его короткое имя (`appname`) и URL опубликованной страницы. PC-PersonalControl не может создать домен, выбрать свободный username или зарегистрировать `appname` вместо владельца. Не публикуйте токен и не встраивайте его в HTML/JavaScript. Веб-панель передаёт только фиксированные действия, доступные привязанному владельцу.

Username нельзя скрыть настройкой PC-PersonalControl; его смена в BotFather не гарантирует, что бота перестанут находить.

Бот выполняется на этом компьютере и для связи использует исходящий HTTPS-запрос к Telegram; входящий сетевой порт не открывается. Если ПК выключен, этот же бот не может его разбудить. Для удалённого пробуждения нужен постоянно работающий узел в домашней сети. Журнал бота находится в `%LOCALAPPDATA%\FanPilot\telegram.log`.
