Ваш ПК в Telegram

Смотрите температуры CPU и GPU, скорость каждого вентилятора и характеристики компьютера прямо в Telegram. Выключайте, перезагружайте и блокируйте ПК одним нажатием. Свой бот и токены не нужны.

Скачать для Windows Открыть бота

Как начать

  1. Скачайте и запустите PC-PersonalControl.exe (нужны права администратора для чтения датчиков).
  2. Согласитесь на «Облачную панель».
  3. В Telegram откроется бот — нажмите Start. Готово.

Обновления

Загрузка…

Все обновления агента ставятся сами и только с цифровой подписью разработчика. Бот обновляется на сервере сразу для всех.

Какие данные уходят на сервер

Имя компьютера, модель CPU/GPU/платы/дисков, объём памяти, температуры, обороты вентиляторов, загрузка. Ничего больше: файлы, экран и пароли не передаются. Команды ограничены фиксированным списком. Отвязать ПК можно командой /unlink у бота.

PC-PersonalControl использует LibreHardwareMonitorLib (MPL-2.0).
