# PC-PersonalControl — облачная сборка

Эта сборка Windows-клиента включает Telegram-обработчик и облачного агента. Основная локальная сборка приложения находится в `../../desktop/`; сервер API, бот и веб-файлы — в `../server/`.

Клавиатура Telegram позволяет менять громкость на 2%, включать/выключать звук, задавать уровень 0–100%, проверять актуальный уровень и управлять воспроизведением: пуск/пауза, предыдущий и следующий трек. Медиаклавиши отправляются в Windows и обрабатываются приложением, которое их поддерживает.

В личном чате бот ежедневно в 00:00 по местному времени удаляет сохранённые ID сообщений владельца и бота, накопленные после включения очистки. Telegram Bot API не предоставляет команду очистки всей истории и не удаляет сообщения старше 48 часов; локальные журналы не затрагиваются.

## Запуск и сборка

Запустите `PC-PersonalControl.exe`. Приложение запросит права администратора для чтения датчиков и управления поддерживаемыми вентиляторами. Компоненты извлекаются с проверкой SHA-256 в `%LOCALAPPDATA%\FanPilot\Runtime`; этот каталог сохранён для совместимости с существующими настройками.

Для запуска PowerShell-исходника используйте `Start-PC-PersonalControl.cmd`. Чтобы пересобрать EXE, откройте 64-разрядную Windows PowerShell в корне репозитория и выполните:

```powershell
& .\cloud\client\Build-PC-PersonalControl.ps1
```

Сборщик проверяет хеши исходников и DLL, используя общую папку `desktop/lib`; второй копии библиотек в облачной сборке нет.

## Облачный агент

Агент настраивается и выпускается инструментами из `../server/README.md`. Устройство и бот связываются через Telegram. Для управления нужны интернет-соединение и включённый ПК; это не удалённый рабочий стол, агент принимает только предусмотренные приложением действия.

Агент отправляет серверу имя компьютера и доступные характеристики оборудования, включая температуры, загрузку и обороты. Он проверяет подпись и SHA-256 перед установкой обновлений агента. Не включайте в релизы пользовательские файлы `%LOCALAPPDATA%\FanPilot\telegram.json`, `cloud.json` и `agent.json`, токены или закрытый ключ подписи.

## Локальные возможности

Приложение показывает только датчики и каналы вентиляторов, предоставленные оборудованием. Поддерживаемые каналы можно регулировать, а при штатном закрытии управление возвращается аппаратному контроллеру. Безопасные температурные пределы остаются под контролем BIOS и драйверов; приложение не меняет напряжение и предел мощности CPU/GPU.

Если приложение завершилось принудительно, запустите `PC-PersonalControl.exe -RestoreDefaults`; для закрытия зависшего экземпляра перед восстановлением добавьте `-CloseProcessId <PID>`.

## Сайт и Mini App

Файлы сайта и Telegram Mini App находятся в `../server/web/`. Настройка публикации, HTTPS, API и релизов описана в `../server/README.md`. Не помещайте токен бота или закрытый ключ подписи в HTML/JavaScript.
